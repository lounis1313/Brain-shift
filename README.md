# Brain Shift 1.1 — NOVELYX Studio

Brain Shift est un jeu d'entraînement cérébral mobile-first : mémoire, calcul mental, observation, logique et contrôle attentionnel.

## Jouer
Après activation de GitHub Pages, l'application sera disponible ici :

**https://lounis1313.github.io/Brain-shift/**

## Fonctionnalités
- 5 mini-jeux : Mémoire Flash, Calcul Express, Intrus Visuel, Suite Logique et Stroop Couleurs.
- 5 niveaux de difficulté + mode Auto personnalisé par discipline.
- XP, niveaux, badges, séries, statistiques et Score cerveau.
- Sauvegarde locale et export/import de progression.
- PWA installable et fonctionnement hors ligne après la première ouverture.

## Confidentialité
La version 1.1 ne nécessite aucun compte et n'envoie pas la progression vers un serveur. Les données de jeu restent stockées localement dans le navigateur de l'appareil.

> Le « Score cerveau » est un score ludique interne à Brain Shift. Il ne constitue pas une mesure médicale ou psychométrique de l'intelligence.
